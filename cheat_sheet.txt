1. LLM (Large Language Model)
──────────────────────────────────────────────────────────────────────

LLM = An AI model trained on a huge amount of text.

Examples:

• GPT
• Gemini
• Llama
• Mistral
• DeepSeek

LLMs predict the next token.

User → LLM → Answer


2. TOKENS
──────────────────────────────────────────────────────────────────────

Token = Smallest unit processed by an LLM.

Example:

"Artificial Intelligence is amazing."

Possible tokens:

Artificial | Intelligence | is | amazing | .

Rules:

1 token ≈ 4 characters

100 tokens ≈ 75 words

1000 tokens ≈ 750 words


3. CONTEXT WINDOW
──────────────────────────────────────────────────────────────────────

Context Window = Maximum amount of information an LLM can process at
one time.

User Prompt
+ Chat History
+ Retrieved Documents
+ Instructions
= Context Window

Refreshing a chat DOES NOT increase the context window.


4. HALLUCINATION
──────────────────────────────────────────────────────────────────────

Hallucination = The LLM invents information.

Example:

User: Who discovered life on Mars?

LLM: Professor Smith discovered life on Mars.

(Incorrect information generated by the model.)

Solution:

RAG

8. CHUNKING
──────────────────────────────────────────────────────────────────────

Chunking = Dividing large documents into smaller pieces.

Example:

Document:

Artificial Intelligence is a branch of computer science.

↓

Chunk 1:

Artificial Intelligence is a branch

↓

Chunk 2:

of computer science.


9. CHUNK OVERLAP
──────────────────────────────────────────────────────────────────────

Chunk 1:

A B C D E

Chunk 2:

D E F G H

D and E are repeated to preserve context.


10. CHUNKING STRATEGIES
──────────────────────────────────────────────────────────────────────

1. Character Chunking

ABCDE
FGHIJ

Simple splitting.


2. Recursive Chunking

Paragraph
 ↓
Sentence
 ↓
Word

Best default strategy.


3. Sliding Window Chunking

ABCDE

CDEFG

EFGHI

Uses overlapping windows.


4. Semantic Chunking

Groups information according to meaning.


5. Agentic Chunking

An LLM decides where to split the document.


11. CHOOSING CHUNK SIZE
──────────────────────────────────────────────────────────────────────

FAQs → 300

Articles → 500

PDFs → 800

Technical Documents → 1000

Recommended:

chunk_size = 800

chunk_overlap = 100


12. EMBEDDINGS
──────────────────────────────────────────────────────────────────────

Embeddings convert text into vectors.

Example:

Dog → [0.23, 0.89, 0.12]

Cat → [0.21, 0.87, 0.11]

Similar meanings produce similar vectors.


13. COSINE SIMILARITY
──────────────────────────────────────────────────────────────────────

Measures the angle between vectors.

1 → Identical

0 → Unrelated

-1 → Opposite

Formula:

(A • B) / (||A|| × ||B||)
